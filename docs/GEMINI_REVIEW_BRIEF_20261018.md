## Проверяемые результаты, а не итоговая оценка качества

Свежий полный прогон трёх JSON, dt1с, seed0, штатный поиск K2..6,
без передачи manual_marks в inference. Сохранённые predictions включают
полный lossless cache извлечённых событий, provenance, индексы отбора,
якоря времени и всю историю; не только удачные отрезки.

После объединения соседних скрытых классов с одинаковой предложенной
конфигурацией сигналов у JSON6 остаётся2 состояния и10 переключений,
но временные границы не улучшаются. Итого19/34 при19/36 предсказаниях;
исходный latent-результат19/41. Не смешивай эти два представления.

Пользователь размечал вручную: возможная **задержка нажатия до3с после
фактического сигнала**. Отдельная оценка проверяет интервал[отметка−3с,отметка],
не симметричные ±3с. Совместимы8/17,3/8,5/9. Ни постоянный сдвиг по truth,
ни сдвиг для каждого файла не подбирались. Первая и последняя отметки
исключены как границы окна. Проверь справедливость самого протокола,
семантику меток и сопоставление разных типов переключений.

Диагностическое согласие анонимных фаз на секундной сетке после оптимальной
перестановки меток96,15/92,19/95,00% не является точностью физических цветов
или независимым holdout. MAE рассчитана только по совпавшим переключениям.
1348 прошедших тестов и браузерные скриншоты не доказывают точность алгоритма.

Первый новый замороженный кандидат — отбор permission-каналов, соответствующих
контролируемым движениям — дал0/17,2/8,0/9. Отклонён, default не изменён.
Его predictions и freeze включены, не рассматривай только baseline-успехи.
На двух других перекрёстках набор только прямых движений был диагностическим
предположением, не подтверждённой схемой оборудования.

## Реальная схема и границы знания

Пользователь явно подтвердил Ленина—Свердловский: **четыре основных светофора;
W и S без допсекций; N и E по одной допсекции**. В прежнем operator review:

- EW={E→W,W→E}, без активных допсекций;
- N_E_ARROW={N→S,N→E,E→N}: у N основной+допсекция, у E только допсекция;
- NS={N→S,S→N}, без активных допсекций.

Исходные operator review и manual_marks включены без исправления содержимого.
Анонимные ручные A/B/C не тождественны внутренним PHASE_A/B/C.
Известная схема добавлена как явное внешнее ограничение. Это **не результат
автоматического восстановления аппаратуры**. Внешний каталог содержит группы,
но не ручные времена/период/длительности. Проверь, не навязывает ли его
сопоставление ответ и не создаёт ли недоказанные цвета.
Для других перекрёстков известная схема Свердловского неприменима.

В активном UI есть отдельная «оценка сигналов» GREEN/RED и стрелки GREEN/OFF;
физически наблюдённые состояния остаются UNKNOWN, жёлтые интервалы не заданы.
Проверь, разумен ли такой вывод для пользователя и не скрывает ли он ошибки.
Не своди полезное решение к UNKNOWN повсюду, но и не объявляй догадку фактом.
