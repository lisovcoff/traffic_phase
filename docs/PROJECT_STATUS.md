# Project status - 2026-10-21

Version 0.13.0 passes the [release audit](../results/release_audit.md) for local
demonstration and code submission within the published accuracy scope. The audit
adds short-transition annotations, fixes stale model bookmarks and updates
installation dependencies. Numerical inference is unchanged from 0568b95.
The short-color weakness remains measured, not hidden or declared fixed. Both
READMEs now include pandas-aggregated statistics and actual player imagery;
the reporting script remains local and ignored.

The offline/online Python application is implemented and checked through its
actual HTTP and browser paths. New models with automatically learned queue
geometry use integrated **causal v8**. Models without references and existing
v7 journals retain v7; issued history is never silently rewritten.

**Physical acceptance remains incomplete.** The newest eight independent SUMO
controls improve total accuracy from 89.57% to 93.51%; strict no-regression
acceptance FAILS on period-change false GREEN and T3 RED_YELLOW. V8 is selected
in the research application for aggregate improvement, not a claimed all-color
or universal 95% acceptance. See [v8 measurements](../results/causal_v8.md).

## Delivered

- Single JSON/ZIP intersection upload, session separation and saved models.
- Automatic observed approaches, K, movement groups and section hypotheses.
- Actual local offline histories, recurring regimes and variable-duration online
  estimates with fixed offline topology. Video and labels are evaluation only.
- Automatic bounded raw-trajectory queue geometry, including a supported incoming
  prefix when the inferred main route turns on a T junction.
- Joint color/age hypotheses, queue-front observations and up to 16 competing
  duration hypotheses; isolated changes do not erase the ordinary program.
- Transactional online journal, duplicate/future validation, exact cold recovery,
  common vehicle/signal player, time selection, replay speed and reload recovery.
- English-default/Russian documentation, source packaging and public compact
  validation records. Raw data and generated research reports remain local.

## Remaining accuracy limits

95% across six archives and a numeric theoretical maximum are not established.
No archive has complete independent lamp truth for all heads/seconds. Enthusiasts
video labels lack an accepted JSON/video clock association; the crash does not
reveal invisible N. Chicherina has no usable independent lamp video. Empty demand,
permissive turns and obstructions can leave colors or hardware unidentifiable.
Startup may show `?` while movement evidence accumulates; the renderer explicitly
labels synchronization. This must not be replaced with fabricated confidence.

The eight latest controls are now revealed. Further model tuning requires a
new frozen evaluation set, separate current/history scores, and explicit
short-color and false-GREEN comparisons. Historical 2D.1 remains FAIL/disabled.
