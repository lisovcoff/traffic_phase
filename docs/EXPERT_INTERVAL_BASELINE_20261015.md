# Новые экспертные интервалы: протокол до расчёта

Base: `7df53eafec2154540aa718ea2bee05e74882f60f`.
Цель — первая воспроизводимая проверка текущей модели на трёх новых датах,
полученных от пользователя. Это development, не untouched holdout. Исторические
19/34 на прежних датах остаются отдельным набором и не являются before этого run.

## Зафиксированные правила

- Интервалы обозначают действие группы. Их крайние начала/концы — границы
  наблюдения; 0 и 180с никогда не считаются переключениями. Даже первый интервал
  с ненулевым началом не становится доказанной границей без предшествующей группы.
- Соседние интервалы разных групп дают внутреннее переключение. При overlap
  сохраняются оба endpoint и ширина расхождения; только для point diagnostic
  используется floor среднего в миллисекундах. Для 6/115мс это фиксированный
  способ учёта рассогласования, не оптимизация по prediction. Ни один endpoint
  не правится в исходных файлах. Произвольный overlap не объявляется точной truth.
- Gaps разрывают блок оценки; дополнительные границы/состояния в них не создаются.
  Unsorted, nested, нулевые и многократные противоречивые интервалы отклоняются.
  Продолжение одной группы не является переключением.
- Неизменный `evaluate_history` вычисляет untyped one-to-one границы при ±2с,
  matched/truth/predicted, precision/recall, MAE/p95, nearest MAE и temporal coverage.
  Перестановочная phase agreement — отдельная диагностика, не physical accuracy.
- Sentinel-концы блоков не участвуют в recurrence period: берутся только
  возвращения к группе по внутренним переключениям без пересечения gaps.
  Recurrence в коротком окне не доказывает стационарность контроллера.
- Авторские группы сохранены независимо от модели. K сравнивается с числом
  заявленных групп. Mapping не передаётся inference; выбранная машина игнорируется
  при назначении группы. Реальные секции остаются UNKNOWN без внешнего основания.
- Заявленные пользователем ≤2с — экспертная оценка, не измеренная lamp error.
  Допуск evaluator остаётся ±2с и не расширяется этой оценкой.

## Один ограниченный запуск

Файлы: 17_2025_2_12_7, 19_2025_2_25_8, 6_2025_2_14_6.
Доступных predictions для этих дат в проверенных results/benchmark manifests нет.
Используется прежний worker `scripts.offline_benchmark infer`: один отдельный
JSON, dt=1с, seed=0, один BLAS/OMP thread, timeout=90с на файл, максимум 3 вызова,
без retries, без изменения extraction/templates/offset/thresholds/defaults.
Production K-search остаётся K2..6, максимум 5 кандидатов, cooperative budget60с;
worker90с — жёсткий внешний предел. Experimental local history выключена.
Полные сеансы используются для discovery; 180с — только область оценки, не
truth-derived training crop. Бюджет суммарно 270с workers, плюс I/O/оценка.

До вызовов сохраняются адаптеры, hashes источников и manifest; code/config
коммитятся. Все predictions и их hashes фиксируются до первого сравнения.
Повторный run того же каталога запрещён marker-файлом. Timeout публикуется как
unavailable. Результаты не используются для повторного подбора параметров.

## Критерии

Сначала должны пройти tests censoring/overlaps/gaps/renaming/recurrence и
запрета review в worker, а также seal всех predictions до scoring. Новая
точность не заявляется по успешному тесту адаптера. После запуска публикуются
все три результата с числом меток и coverage, включая неверный K/timeout.
Любое дальнейшее алгоритмическое изменение требует отдельной гипотезы и проверки.
Независимая calibration и validation остаются открытыми; исходный 2D.1 FAIL сохранён.
