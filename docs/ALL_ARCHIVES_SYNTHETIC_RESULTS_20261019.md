# Все архивы и реалистичная синтетика: результаты 19.10.2026

**Универсальная точность текущего алгоритма не подтверждена.** Обработка всех
доступных исходников работает, но автоматическое число фаз совпало только
в 13/72 синтетических сценариев (18,1%). Этот этап измеряет существующий
алгоритм; новые модели по контрольной истине не обучались.

Открыть [интерактивный отчёт](../evidence/all_archives_synthetic_20261019/report.html).
В нём все источники, сравнение распределений, график «истина / прогноз»,
результаты видимого светофора и ссылки на локальные входные ZIP.
[Обычный просмотрщик реального Свердловского ZIP](../evidence/all_archives_synthetic_20261019/application_checks/sverdlovsky/viewer.html)
показывает текущий обученный режим без поправки из видео.

## Реальные исходники

Полностью прочитаны 216 JSON из шести транспортных ZIP и три отдельных JSON:
46 422 544 092 байта, 667 533 трека, 134 648 606 детекций. У каждого члена
архива проверен CRC и сохранён SHA256. Три отдельных JSON совпадают с членами
архивов: уникальных источников 216. Объёмы треков/детекций выше включают копии.
Два ZIP с кодом/тестами исключены из транспортной выборки.

Автоматический режим отработал на всех 219 источниках; замороженные обученные
профили также отработали на всех 219. Члены архивов и сеансы не объединялись.
Первый проход сохранил диагностические часовые окна обученного режима;
отдельный повтор из тех же событий применил производственное ограничение окна
10800 с. Проверка ручных меток и видео использует второй вариант.
Успешная обработка не доказывает точность светофоров на неразмеченных часах.

## Синтетика

72 сценария, 62 часа, 101 960 треков и 54 694 888 детекций. Основные 70 сценариев
заморожены до запуска; отдельно добавлены два сценария неравных фаз/короткой
стрелки с E→_E, уступающим реальному смоделированному потоку W→_E.
Для датчика и классов машин использована выборка из каждого из шести архивов;
жёлтый 3 с согласуется с прежними независимыми видеобрекетами обоих участков.

План сигналов задан до движения. Есть очереди, ускорение/торможение, реакция
водителя, ограниченное поле камеры, редкие/плотные потоки, пачки машин,
перекрытие выезда, уступание, смена цикла, пропуски, дубли и разрывы ID.
Геометрия, динамика и красно-жёлтый 2 с остаются предположениями симулятора.
Единицы speed поставщика не подтверждены; синтетика явно использует км/ч.
Сходство распределений измерено в отчёте, полного реализма не заявляем.

В алгоритм переданы только траектории/события под нейтральным именем records.
Истина сохранена отдельно и хеширована до вызова прогнозирования. Ни видео,
ни число фаз, ни имя сценария не передаются функции прогноза.

| Показатель по полной длительности | Результат |
| --- | ---: |
| Правильное число фаз | 13/72 = 18,1% |
| Ошибка логического состояния, включая UNKNOWN | 42,1% времени |
| Покрытие логической истории | 89,9% |
| Границы логических фаз в ±2 с | 1661/6474 = 25,7% полноты |
| Подтверждённые предсказанные границы в ±2 с | 1661/7100 = 23,4% |
| Ошибка цветов четырёх основных голов, включая UNKNOWN | 36,4% времени голов |
| Покрытие цветов основных голов | 81,1% |

Цвета получены настоящим автоматическим проектором приложения без профиля
известного перекрёстка и без подстановки схемы из истины. У семи сценариев
физическая схема не определилась. Отдельные дополнительные стрелки этим
физическим показателем не покрыты. Сетка состояния/включений цветов 0,25 с;
логические границы сравниваются по исходным временам. Совпадения однозначные:
одна истинная граница не засчитывается нескольким предсказаниям.

| Включение основных голов, ±2 с | Найдено / истинных | Подтверждено / прогнозов |
| --- | ---: | ---: |
| GREEN | 2105/8366 | 2105/6420 |
| YELLOW | 1575/8412 | 1575/6402 |
| RED | 1575/8411 | 1575/6408 |

Частая ошибка — лишняя фаза; правильное K само по себе не гарантирует
правильный период, состав фаз и их границы. В обычных сценариях K совпало
2/8, при общем основном зелёном через смену стрелки — 0/2, на четырёхчасовых
записях — 0/2. Полные результаты всех сценариев сохранены, включая неудачные.

Два сценария starved намеренно оставляют фазу без машин. Дополнительно
[построен проверяемый контрпример](../evidence/all_archives_synthetic_20261019/nonidentifiability_witness.json):
один ZIP соответствует планам с 3 и 4 фазами при точно одинаковых интервалах
сигналов всех наблюдаемых движений. Это конструктивное доказательство
ненаблюдаемости полного плана в таком случае, не 73-й независимый тест.
Оно не объясняет ошибки на остальных сценариях.

## Реальные контрольные метки

Повтор прежних вторых половин ручных разметок без переобучения и без передачи
контрольных меток прогнозу. Прогноз по полной записи отличается от прежней
проверки на коротких окнах, поэтому прежние 11/13 здесь не подставлены.

| Режим | Границы в ±2 с от метки | Совместимы с реакцией 0..3 с |
| --- | ---: | ---: |
| Автоматический | 7/13 | 6/13 |
| Обученный | 10/13 | 3/13 |

Интервал реакции — [метка −3 с; метка]. Прогноз после метки может попасть
в симметричный допуск ±2 с и не попасть в этот интервал. Это операторская
разметка фаз, не точные физические цвета; повтор не является новым holdout.

На прежних девяти видимых N-main переключениях Свердловского, 3300..3600 с,
автоматический режим без видеопоправки попал в 0,5 с от брекета для 1/3 GREEN,
0/3 YELLOW и 0/3 RED. Обученный без поправки — 0/3 по каждому цвету.
Диагностический повтор с прежней поправкой конкретного источника даёт 9/9;
он исключён из оценки универсального алгоритма и из обычного просмотрщика.
Это три цикла той же записи с условной привязкой часов, не новый день.

У Энтузиастов независимая связь часов JSON/видео не принята; точность ламп
не объявляется. Видео Чичерина не удалось получить: Яндекс возвращает пустое
тело, пользователь тоже не смог скачать. Превью не использовано как истина.

## Что изменено в приложении

В обычном обученном просмотрщике отключён автоматический выбор видеопоправки
по SHA конкретного архива. Тест запрещает такой lookup. Диагностическая
утилита, конфигурация и прежние доказательства сохранены. На странице указано,
что обученный режим использует готовые профили, а K задан обучением.
Боевой вход — JSON/ZIP; видео нужно только для проверки разработчиком.

Сам решатель фаз, обученные профили и main не изменены. 2D.1 остаётся
FAIL/default-off; новых экспериментов с декодером или переобучением не запускали.

## Проверка и воспроизведение

Подробные статусы проверок — full_tests_idle_receipt.json, startup_check.json
и browser/receipt.json в каталоге отчёта. Первый запуск тестов под тяжёлой
пакетной нагрузкой имел один сбой ограничения 5 с; его журнал сохранён отдельно.
После завершения пакетных задач полный повтор: **1410 passed**, включая прежний
тест времени выполнения; 5 предупреждений. `START_WEB.cmd --check` также PASS.
Отчёт и реальный просмотрщик проверены в изолированном Edge: desktop/mobile,
поиск, 72 сценария, перемещение по времени, воспроизведение, N/E со стрелками
и W/S без них. JS-ошибок и горизонтального переполнения нет. Первая попытка QA
выбрала секундный сегмент уже одного пикселя на часовой шкале; попытка сохранена.
Повтор проверил настоящий щелчок по видимому длинному сегменту, без force-click,
и прошёл. Итоговые скриншоты/receipt — browser_v2; browser/receipt.json связывает
обе попытки. Для точного времени в приложении остаётся отдельный ползунок.
