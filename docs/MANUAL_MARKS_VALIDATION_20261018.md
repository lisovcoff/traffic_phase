# Ручная разметка и схема Свердловского, 18.10.2026

По прямому заданию пользователя заново обработаны все три полных trajectory JSON
из `../data/ручная разметка/`. Инференс получает только траектории, без отметок,
фаз A/B/C, фиксированного K и временного сдвига. Протокол и бюджеты зафиксированы
в `MANUAL_MARKS_RUN_PROTOCOL_20261018.md`; predictions и SHA-256 сохранены до оценки.
Это знакомые данные разработки, не независимая проверка физических ламп.

Исправлена подтверждённая пользователем схема **Ленина—Свердловский**:

| Подход | Основной | Допсекция |
|---|---|---|
| N | N→S | N→E |
| S | S→N | отсутствует |
| E | E→W | E→N |
| W | W→E | отсутствует |

Из прежнего operator review взяты группы EW={E→W,W→E},
N_E_ARROW={N→S,N→E,E→N}, NS={N→S,S→N}. Каталог не содержит времен отметок,
периодов и длительностей. Анонимные классы сопоставляются группам по
характеристикам потоков; при неразличимых характеристиках результат недоступен.
Профиль применяется к явно выбранному перекрёстку, имени со «Свердлов» или трём
известным именам JSON17. Для других перекрёстков это не аппаратная истина.

## Что изменено в приложении

В форме добавлен выбор схемы. При доступном сопоставлении по умолчанию показаны
**«Сигналы по модели»**: основные GREEN/RED, установленные допсекции GREEN/OFF.
N/E сохраняют допсекции даже в погашенном состоянии, W/S их не получают.
Жёлтые интервалы без данных не придумываются. Отдельный режим физических
наблюдений остаётся UNKNOWN. В протоколе экспорта оценка хранится отдельно в
`estimated_signal_history.json`; физический `signal_timeline_0.1s.jsonl`
сохраняет UNKNOWN и подтверждённый состав секций.

Используется фактическая локальная история HSMM. Соседние классы с одинаковыми
состояниями светофоров объединяются; пробелы и конец истории сохраняются.
Циклического повторения вместо истории нет. Исходные скрытые классы и их
предсказания сохранены. Исправлено перекрытие коротких кнопок временной шкалы
из-за стандартного padding: настоящие клики проверены браузером.

## Полученные результаты

Строгий прежний допуск ±2 с сохранён. Первая и последняя отметки исключены как
границы окна. MAE ниже относится **только к совпавшим границам**, а не ко всем.

| JSON | Скрытые классы / метки | Состояния схемы | Совпало ±2 с | Предсказано границ | MAE совпавших |
|---|---:|---:|---:|---:|---:|
| 17_2025_2_19_10 | 3 / 3 | 3 | 15/17 | 18 | 0,709 с |
| 19_2025_2_24_16 | 2 / 2 | 2 | 1/8 | 8 | 1,546 с |
| 6_2025_2_14_20 | 3 / 2 | 2 | 3/9 | 10 (было 15) | 1,471 с |

Для JSON6 автоматическое предложение схемы уже сопоставляло два разных скрытых
класса одной фазе EW. Проекция теперь убирает пять лишних переключений без
перемещения оставшихся границ. Итого 19/34 правильных по прежнему допуску,
19/36 предсказаний после объединения против 19/41 до него. Это улучшение
структуры вывода, не улучшение времени. Исходный автоматический K по-прежнему
3/2/3; условный результат по известному каталогу нельзя считать автоматическим
обнаружением аппаратуры или K.

Заявленная пользователем задержка нажатия 0–3 с оценивается отдельно:
допустимый истинный момент находится в [отметка−3 с, отметка]. Это не ±3 с.
В этот односторонний интервал попало 8/17, 3/8 и 5/9 границ соответственно.
Сдвиг по разметке не подбирался. Простая задержка реакции не объясняет все
ошибки, в том числе предсказания после отметки. Согласие анонимных фаз на
секундной сетке с перестановкой меток: 96,15%, 92,19%, 95,00% после объединения;
это диагностическое согласие фаз на знакомых данных, **не точность цветов**.

Первый замороженный кандидат с фильтрацией permission-каналов дал совпадения
0/17, 2/8, 0/9 (до объединения). На Свердловском и Энтузиастов стало хуже.
Кандидат **отклонён**, в приложение не включён, отрицательные predictions
сохранены. Для двух других перекрёстков фильтр прямых движений был только
диагностическим предположением. Второй разрешённый кандидат не запускался;
продолжение модельных экспериментов требует отдельной конкретной гипотезы.
