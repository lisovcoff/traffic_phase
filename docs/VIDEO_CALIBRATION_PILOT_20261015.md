## Что сделать в программе

1. Запустить внешний `START_ANNOTATION.cmd`, открыть http://127.0.0.1:8011/annotation.
   Выбрать указанный `calibration_tracks.json`, начало окна **77.852**, длительность
   **180**, своё имя/псевдоним. Нажать «Открыть JSON». Начало координат времени
   целого файла — 10:02:42.148; 77.852 соответствует 10:04:00.
2. Раскрыть «Видео рядом», выбрать исходный MP4 из Downloads. Он остаётся локальным,
   на сервер не загружается. Для начала поиска 10:04:00 ориентир видео **245.067 с**;
   это предварительный расчёт по часам камеры, НЕ проверенная синхронизация.
3. Найти минимум три однозначно узнаваемые машины в начале, середине и конце окна.
   Для каждой сопоставить один и тот же наблюдаемый момент видео и JSON, выбрать
   машину и сохранить событие `sync_anchor` с источником «Видео». Кнопка «Взять
   текущую позицию видео» копирует media time; «Связать с текущей позицией» сохраняет
   пару времён. Указать в заметке признаки машины, способ сопоставления и точность.
   При невозможности сопоставления оставить синхронизацию непроверенной.
4. Для светофора нажать «Выбрать область на видео», затем на нужную секцию.
   Увеличение использует исходные пиксели, не распознаёт цвет. Кнопки ±0.1 с
   перемещают курсор, но не обещают точность времени 0.1 с.
5. Размечать видимые состояния/переходы как «Наблюдаемый сигнал», источник «Видео»,
   названия вроде `H1 GREEN`, `H1 RED`, `H1 UNKNOWN`. Времена начала/конца задавать
   в координатах JSON только после проверки привязки. Для перехода интервал охватывает
   последний достоверный старый и первый достоверный новый кадр. Для длительности
   состояния явно написать «интервал состояния»; края окна не считать переключениями.
   Закрытая/нечитаемая секция — UNKNOWN. Не назначать направление или стрелку по повороту машины.
6. Нажать экспорт JSON и передать файл разметки. Видео повторно присылать не нужно.
   Каждая метка сохраняет собственную привязку и ROI; последующие изменения не меняют
   старые метки. Статус independent verification не выставляется автоматически.
