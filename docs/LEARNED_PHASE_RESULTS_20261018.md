## Что реализовано

`app/core/learned_phase.py` строит плотности событий движения и начала движения
по циклу. Суммарный вес событий одной машины ограничен единицей. Для нового
наблюдения циклическое динамическое программирование восстанавливает локальную
историю по событиям и периоду; пустые секунды не считаются признаком красного.
Количество и смысл фаз поступают из обучающей разметки. В прогнозе нет
аргумента с контрольными метками и нет подстановки известных переключений.
Период определяется по транспортным данным всей выбранной записи: это офлайн
метод, использующий в том числе будущие неразмеченные события.

В `config/learned_profiles/` включены три сохранённые модели. Их параметры
плотности и начала фаз скопированы из запечатанных обученных моделей. Сигнатуры
движений для отображения вычислены только по обучающей половине. Загрузка
нового JSON/ZIP не требует разметки. Выбор другого известного перекрёстка для
источника с опознаваемым префиксом отклоняется. Для ZIP приложение запрашивает
конкретный JSON и, при необходимости, сеанс; они не объединяются молча.

Для Свердловского показана подтверждённая пользователем схема: четыре основных
светофора, дополнительные секции только N→E и E→N, без секций на W/S. Цвета —
оценки модели; жёлтые переходы не определяются. Для остальных перекрёстков
показаны движения модели, неподтверждённая конструкция светофоров не создаётся.
Наблюдаемые лампы остаются UNKNOWN; обнаружение отклонений этим режимом не
реализовано, интерфейс честно показывает «Не оценено».

## Проверки и отрицательные результаты

Два новых автоматических алгоритма написаны отдельно от старого EM/Bernoulli:
count segmentation и вариант с совмещением событий одной машины. Их строгие
результаты по полным размеченным окнам: соответственно 6/17,1/8,2/9 и
1/17,0/8,1/9. Они проиграли и не заменяют рабочий алгоритм. Сохранены код,
протоколы и все отрицательные результаты в `benchmarks/count*_20261018/`.

Первая обученная версия дала 12/13, но независимый тест равномерного
120-секундного цикла выявил численную ошибку: фиксированная сетка из 100
состояний заставляла MAP-часы двигаться неверно. Тест сначала падал, затем
прошёл после привязки числа состояний к периоду в секундах. На тех же сохранённых
обученных моделях, без повторного обучения и подбора параметров, получено
**11/13**. Именно этот более низкий результат считается итоговым. Оба набора
прогнозов и протокол исправления сохранены.

Реально распакованы и обработаны ZIP «Ленина-Свердловский 27.02.25.zip» и
«Ленина-Энтузиастов 05.10.24.zip». Проверены первые по имени JSON и первый
наблюдаемый сеанс: `17_2025_2_27_10.json` и `6_2025_2_23_13.json`.
Результаты содержат соответственно 3897 и 237 отображаемых траекторий.
Остальные JSON/сеансы не анализировались; на этих записях нет независимых меток
ламп, поэтому это проверка интеграции, а не новая оценка точности.

Полный набор тестов: 1367 PASS, пять существующих предупреждений. После правок
названий фаз и статуса отклонений — ещё 26 соответствующих тестов PASS.
Изолированный Edge проверил два актуальных HTML: воспроизведение, паузу,
перемотку, фазы и мобильную ширину; ошибок JavaScript нет. Проверен реальный
HTTP POST 13 542 804 байт JSON из ZIP через текущий FastAPI: 200, без разметки.
PowerShell оформил предупреждение Starlette в stderr как ненулевой статус
обёртки; assertions, receipt и SHA сохранённого ответа проходят проверку.

Исходные архивы, разметка и прежние результаты не удалялись и не откатывались.
Main сохранён. Исторический эксперимент 2D.1 остаётся FAIL/default-off.
Срок 20:00 по Екатеринбургу в этом сеансе пропущен; этот результат не был готов
к указанному времени.

## Как открыть

Готовые страницы без сервера находятся в `evidence/learned_release_20261018/viewers/`
и `../deliverables/traffic_phase_learned_20261018/`. Сводка —
`evidence/learned_release_20261018/summary.html`.

Для новой загрузки: запустить `START_WEB.cmd` и открыть
http://127.0.0.1:8017/visualization/learned. Если сервер уже работал до обновления,
остановить его Ctrl+C и запустить снова. Выбрать перекрёсток, загрузить JSON/ZIP,
выбрать источник и сеанс, нажать запуск. Обычный `/visualization` сохранён как
отдельный автоматический режим.

## Границы доказанного

Это временное разделение внутри трёх знакомых записей, а не независимый новый
день или новый перекрёсток. Количество фаз обучено, а не обнаружено. Оператор
сообщил о задержке нажатия до 3 с; контроль ±2 с сравнивает с его отметками,
а не с измеренными моментами переключения ламп. На неизвестных режимах и
изменениях схемы качество не доказано. Нельзя заявлять теоретический максимум,
идеальность или физическую точность светофоров.
