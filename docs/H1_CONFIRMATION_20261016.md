## Определение timestamp в предоставленном источнике

Проверены только относящиеся к `millis` абзацы `data/Инфо.docx` (SHA сохранён):

- top-level `millis`: время в миллисекундах, когда ТС уехало с перекрёстка;
- `detections[].millis`: время обнаружения;
- отдельное предупреждение: некоторые ДТП обрабатывались по видео не в реальном
  времени, поэтому millis может не совпадать с реальным временем события.

Последнее предупреждение не уточняет поле и не доказывает, что именно запись
27.02 имеет такой сдвиг. Оно также не разрешает автоматически исключить проблему
для detections timestamps. Часы-источник, timestamping latency и способ
переноса времени из видео не определены этими абзацами. Top-level departure
millis не заменяет detection time и не является crossing стоп-линии.

У пользователя запрошено происхождение clocks для `detections[].millis`:
камера либо сервер обработки/неизвестно. Ответ пока не внесён. Даже сообщение
о тех же часах будет provenance, а не само по себе численной оценкой uncertainty.

## Соответствие H1 движениям

Уже подтверждённое пользователем знание сохранено без повторного вопроса:
H1 относится к нижнему подъезду; основной — прямо вверх-вправо, боковая секция
— налево вверх-влево. Статус `OPERATOR_CONFIRMED_VIDEO_RELATIVE_DIRECTIONS`.

Связь с raw labels имеет **локальную поддержку**: source SHA выбранных7 tracks
совпадает с frozen model; из прежних anchors4 автомобиля не участвовали в fit.
У3 raw zone pair `N->_S`, у1 `N->_E`;18 видимых точек, максимальные остатки
20.54/20.68/12.05/42.26px проходят прежний объявленный50px gate.
Эти scores не вычислялись заново и геометрия не переобучалась.

В sidecar сохранены proposals `main→N->_S`, `lateral→N->_E`, `verified=false`:
это поддержанные соответствия для дальнейшей calibration, не независимое
подтверждение всех направлений/разрешений. Определение centroid, vehicle identity,
полная траектория поворота относительно H1 и joint clock/geometry error не
сертифицированы. Protected/permissive semantics UNKNOWN; факт поворота не
доказывает аппаратную стрелку. Production mapping этим sidecar не заменён.

## Результат и следующий шаг

`python -m scripts.check_h1_confirmation` проверяет source hashes, frame hashes,
связь frozen model с raw-anchor source и выдаёт отдельно факты/readouts/ограничения.
`evidence/h1_confirmation_20261016/` содержит readouts, excerpt, confirmation,
manifest и commands.log.25 targeted tests проверяют, что успешная registration,
readout, supplier warning или изменение delta не повышают статус clock/hardware,
а повреждённые frame references/PTS отвергаются. Исходники неизменяемы.

Для следующего calibration эксперимента остаётся определить источник detection
timestamps и обосновать совместную модель image/clock/identity погрешности.
Нужен отдельно замороженный ограниченный протокол; нельзя подбирать offset по
phase errors или подменять его driver reaction delay. Текущая работа дала
подтверждённые **частичные** связи, а не полное подтверждение синхронизации.
2D.1 FAIL и historical metrics сохранены; main/default не менялись.
