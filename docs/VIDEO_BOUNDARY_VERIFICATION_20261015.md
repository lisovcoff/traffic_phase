## Синхронизация: что проверено и что осталось

Повторно просмотрены ранее сохранённые полные кадры275/335/395с с часами камеры
10:04:30/10:05:30/10:06:30. Из локального JSON взяты все ближайшие реальные
detections в пределах150мс этих времён, без интерполяции. Их список и потенциально
различимые грузовик, эвакуатор, троллейбус сохранены в synchronization_check.json.
Эти категории и совпадение примерного времени **не доказывают идентичность ТС**.
Подтверждённых same-car anchors нет. Прямое совмещение bbox/centroid с видео,
геометрический transform и определения координат не подтверждены. Нельзя получить
субсекундную синхронизацию из одной приблизительной ручной привязки или из названия MP4.

Следующая конкретная задача пилота — установить3 однозначные пары одного ТС
на видео и в JSON с моментом/интервалом сопоставления; при геометрическом преобразовании
сохранить его независимые опорные точки и погрешность. Затем отдельно оценить
clock offset/drift и uncertainty. Не оценивать offset по совпадению предсказанных фаз.
Результаты этого review пригодны для section-specific video calibration, но ещё
не для заявления о синхронизированной lamp accuracy или модели event→signal delay.
