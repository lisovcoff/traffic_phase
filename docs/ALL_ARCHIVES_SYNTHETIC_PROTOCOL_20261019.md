# All-source validation and traffic simulation, 2026-10-19

Authorized scope: all available raw traffic archives and loose raw JSONs, plus
large realistic synthetic tests. Video is independent validation material only.
No changes to the default solver or frozen site profiles in this round.

Freeze before running: automatic V9 uses its existing 2..6 candidate search,
5 candidates/60 seconds, permission_per_stream and experimental history OFF.
The separate learned mode uses the three existing frozen operator-trained site
profiles; its K is supplied by training labels, not discovered automatically.
Record file/session exceptions, abstentions, incomplete searches and selected
representative windows. Successful execution is not a claim of signal accuracy.
All ZIP members are read to EOF (CRC checked) and SHA256 hashed. Three loose raw
sources are included; equal content is recorded as duplication, not new evidence.
Historical predictions, review annotations and code/fixture ZIPs are not traffic.

One canonical ingestion pass also collects bounded distribution samples. The
in-memory production adapter uses source namespace `records`; preserve the real
archive/member separately, and partition sessions inside each member. Never pool
different members or unrelated sessions. Save compressed evidence caches outside
Git for reproducing additional checks without repeatedly reading 46 GB.

Synthetic truth is generated by a traffic queue simulation, before inference.
Measured traffic cadence, vehicle classes, track lengths and flow ranges inform
the generator; frozen video evidence informs the 3-second yellow assumption.
Physical signal onsets differ from vehicle reaction/discharge/crossing events.
Generate multiple K, demand levels, geometry, cycle lengths, startup/headway
delays, permissive yielding, congestion, detection gaps, duplicates and fragments.
Include phase starvation and a pair of different signal plans producing exactly
the same observations. Such inputs cannot establish universal identifiability.
Do not tune the solver against the resulting test truth. Public test seeds and
source distribution provenance are recorded, not presented as an unseen real
intersection accuracy certificate.

Report K and period error, permutation-invariant movement grouping, one-to-one
transition precision/recall at 0.5/1/2/3 seconds, per-state time-weighted error
where signal mapping exists, abstention, runtime, track/detection volume. Count
all failures in denominators. Separate physical signals from logical phases.
No accuracy score for real data without clock-linked independent truth. Keep
operator marks (0..3-second reaction lag) separate from direct video brackets.

Inference isolation: prediction receives trajectories/events and optionally a
frozen training profile, never evaluation truth or video. A test denies filesystem
access to annotation/video/evidence paths during inference. Source-specific
timing corrections must keep their existing exact-content SHA gate.

Chicherina public video is optional evidence. Inspect native frames and clocks;
without a visible lamp it cannot provide direct signal labels. Do not match
traffic periodicity to lamps to manufacture a clock link. Existing conditional
Sverdlovsky and unresolved Enthusiasts clock evidence retain their stated limits.

Execution clarification (before visible-head replay): the first all-member pass
also runs learned diagnostics in independent <=1h windows. A separate replay
from the exact same cached events uses the production predictor's <=10800-second
window bound, so an artificial 1h boundary is not confused with app behavior.
Both sets of receipts are retained. Signal accuracy comparison uses this latter
replay, never the diagnostic chunk boundaries. Neither pass retrains a profile.

Simulation environment is frozen from the first256 trajectories of the
median-size member in EACH of the six archives (1536 tracks). This samples all
supplier archives without waiting for all216 full-member fits. Prefix hashes
are explicitly not full-file hashes/CRC verification. The complete all-source
scan remains mandatory and supplies final distribution/coverage comparisons.
Native Chicherina downloads return empty bodies via both public download routes;
the user independently reports inability to download. Keep this external blocker
in the report, without manufacturing signal labels from a supplier thumbnail.

The main70-case suite was sealed before execution. A separate two-case supplement
is sealed in synthetic/suite_extra.json: strongly unequal2-phase timing and a
short3-phase arrow with continuing main, both with E->_E waiting at an internal
yield point for the actually simulated W->_E crossing calendar. The production
adapter currently excludes same-approach E/_E tracks; report that coverage limit.
New conditional simulator options do not change the original70 inputs.

Final evaluation_v2 uses the entire requested recording as denominator, including
model gaps and unselected representative windows. It canonicalizes zone names
and delegates color transitions to production apply_signal_timing. Earlier
intermediate/pilot receipts are retained, not substituted for final scores.
The exact-source video-calibrated row is a retrospective diagnostic ONLY and is
excluded from universal/no-video accuracy. No production solver was changed.

Disposable Windows workers use the OS architecture environment variable instead
of Python3.12's failing WMI machine query before scientific-library imports.
This changes worker initialization only; application code, algorithms and seeds
are unchanged. A heavily loaded full pytest run had one wall-clock latency test
failure; keep its log and rerun that check after the batch load has stopped.

The standalone report exposes local raw-input ZIP links separately from truth.
