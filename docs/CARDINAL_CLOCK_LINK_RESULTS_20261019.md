# Независимая сверка видео и JSON, 2026-10-19

Свердловский: независимые новые автомобили подтвердили прежнюю гипотезу часов,
не использующую светофорные прогнозы. Это позволяет отделить сдвиг часов от
запаздывания оценки основного N. [Просмотр до/после](../evidence/cardinal_clock_link_20261018/visible_head_comparison.html)
работает с локальным исходным MP4, без сервера и загрузки видео в сеть.

## Назначения голов

Последняя поправка пользователя: «на видео n => e и в джсоне n =>e. ранее я
перепутал». Стрелка N→E; прежнее описание относительного поворота больше не
используется. Это не разрешение переставить E/W во всех источниках. Основной
видимый сигнал обслуживает N. По Энтузиастов пользователь подтвердил E и
одинаковую работу основных E/W. Наблюдение E не считается вторым независимым
наблюдением W. Точные ответы сохранены в user_head_corrections.json; прежние
ответы и video-only метки не переписаны.

## Часы Свердловского

Прежняя геометрия и delta из local_vehicle_registration_20261015 заморожены.
Три разных движущихся машины проверены на соседних кадрах около900/1800/2700с.
Четвёртая около3300с добавлена по записанному до извлечения плану, чтобы не
экстраполировать часы за последнюю проверку в контрольном видеоокне. На каждую
машину приходится три кадра с интервалом около0.5с. Точки кузова размечены по
кадрам без наложенных прогнозов, по прежнему признаку center X/75% высоты.
Второй человек разметку не проверял. Связи ID эмпирические, не сертифицированы
поставщиком; направление движения и тот же автомобиль проверены по последовательности.

| JSON ID | PTS около, с | Максимальная ошибка frozen H/delta, px |

| 9917625 | 900 | 10.589 |

Все прошли заранее установленный допуск50px. Нулевая delta не прошла.
Формула: `JSON_ms = 1740632395000 + 1000*(video_PTS_s + 1.2538380162)`.
Общий условный диапазон delta:1.126901866..1.368506726с. Он учитывает только
допуск локализации при фиксированных геометрии/личностях машин/определении точки.
Не включает неизвестную систематическую ошибку геометрии, экспозиции и устройства;
это не статистический доверительный интервал. Скорость часов принята единичной,
дрейф не подбирался. Проверка охватывает исследованные участки, не все два часа.

## Поправка оценки N main

Прежнее правило median signed error на видео900–1500с сохранено без нового
подбора. Его результат переведён в независимо поддерживаемую шкалу JSON:
green3.897667−1.253838=2.643829с; red4.939333−1.253838=3.685495с.
Условные диапазоны при вариации delta: green2.529..2.771, red3.571..3.812с.
Прогнозируемое время в JSON сдвигается раньше на соответствующее значение.

Контроль2700–3300с уже исследован в предыдущем раунде. Это повторная оценка
с прежними метками, а не новый независимый holdout, параметры под неё не менялись.
После поправки6/6 зелёных и5/5 уверенных красных в0.5с от интервалов кадров.
MAE по серединам green0.192с/red0.053с; эти малые числа не включают clock envelope.
Один зелёный bracket намеренно широкий2.467с, один красный видеоцикл не размечен.
Его несопоставленный прогноз нельзя объявлять установленным false positive.

Доставлены mapped_main_truth.json (22 метки, фиксированные и расширенные интервалы
в шкале JSON), calibrated_N_main_onsets.json (оценки модели), evaluation.json,
clock_aware_calibration.json и новый HTML viewer. Корректируется только N main;
полный план фаз, стрелка, жёлтый, мигание и остальные головы не валидированы.
Production-профили остаются прежними. Нельзя сдвигать все фазы одинаково или
выдавать калиброванную оценку за прямое наблюдение лампы.
