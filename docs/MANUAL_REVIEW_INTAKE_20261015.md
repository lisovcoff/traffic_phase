Проверены файлы из внешнего `data/`; исходники не изменены. SHA256 и размеры
всех трёх trajectory JSON совпали с экспортами. JSON читались блоками только
для хеширования; inference, fitting, benchmark и архивы не запускались.

Пользователь подтвердил 2026-10-15: интервалы — **всё время действия группы**,
несмотря на подпись «Начало группы», а не интервал неопределённости переключения.
Заявленная ошибка относительно реального сигнала — максимум 2с, объяснённая
реакцией водителей. Это сохранённая оценка оператора, не измеренная граница
ошибки и не calibrated interval. В оригиналах timing uncertainty остаётся null.
На Энтузиастов пользователь отмечает низкий спрос; две другие записи считает
достаточно наполненными. Независимого измерения плотности здесь не было.

Это полнота ручной разметки окна, не camera coverage и не accuracy алгоритма.
Все последние интервалы заканчиваются ровно на 180с: правый конец цензурирован,
не является доказанной границей фазы. Начальный край Чичерина также не следует
считать наблюдённым переключением. Внутри окон 5/3/3 соседств интервалов;
две пары endpoints расходятся на указанные миллисекунды, единственная точка
границы пока автоматически не назначается.

Группы сохранены в авторской нумерации, без перестановки по predictions:

Описание допсекций сохранено дословно. Selected car/movement в метке — контекст

разных фаз. Его fingerprint в этом приёме повторно не проверялся.

Экспорты явно имеют role=development и trajectory_with_onsite_knowledge.
Это новые даты записей, но не автоматически независимый holdout или lamp truth.
Материалы пригодны для экспертной проверки структуры и будущего development
сравнения. Независимые сигналы/синхронизация и отдельный validation session
остаются открыты; 2D.1 FAIL и прежние метрики сохранены.
