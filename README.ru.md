# Traffic Phase

[English](README.md) · **Русский**

[![Тесты](https://github.com/lisovcoff/traffic_phase/actions/workflows/tests.yml/badge.svg)](https://github.com/lisovcoff/traffic_phase/actions/workflows/tests.yml)

Восстановление фаз светофора по траекториям машин, когда сами сигналы не видны.
Загрузите JSON или ZIP одного перекрёстка и просматривайте машины и оценённые
сигналы в общем офлайн/онлайн-плеере.

Приложение на Python определяет наблюдаемые подъезды, число фаз и гипотезы
секций из загруженной записи. Видео и разметка ламп нужны только для проверки
результатов и не поступают в алгоритм.

![Плеер: записанные машины и оценённые сигналы](results/figures/player.png)

## Запуск

Нужен Python 3.12. На Windows:

```bat
INSTALL.cmd
START_WEB.cmd
```

Откройте **http://127.0.0.1:8017/visualization**, выберите исходный JSON/ZIP
и нажмите **«Анализировать»**. Одна загрузка относится к одному перекрёстку.
В плеере доступны выбор записи, воспроизведение, скорость, перемотка и переход
к точному времени.

Linux/macOS:

```sh
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8017
```

Для онлайн-работы откройте готовую модель и выберите **«Онлайн»**. Отправляйте
текущие пакеты на POST-адрес из панели или выберите секундный поток JSONL.
Архив можно преобразовать без изменения исходника:

```sh
python -m scripts.archive_online_packets data/intersection.zip --spool .web_runtime/feed.sqlite3 --output .web_runtime/feed.jsonl
```

Каждый раз указывайте новые выходные пути. JSON с манифестом или отчётом не
содержит входных траекторий. Модели и принятая история сохраняются в
`logs/intersection_projects/`; сохраните эту папку при переносе готового анализа.
Формат пакетов, обновление моделей и проверки описаны в [руководстве](GUIDE.ru.md).

## Метод и ограничения

Офлайн-анализ разделяет записи и часы, выделяет признаки движения, находит
повторяющиеся конфигурации и обучает геометрию очередей и длительности.
Онлайн сохраняет эту структуру и обновляет совместные гипотезы цвета, возраста
фазы и длительности по текущему и предыдущему движению. Конкурирующие программы
помогают учитывать разовое продление и повторяющуюся смену периода. Пустая
очередь не доказывает красный; «?» означает недостаток признаков или синхронизацию.

Цвета и физические секции являются оценками. Короткие переходы явно помечены
как оценка времени. Универсальные 95% на шести реальных архивах не доказаны.

| Измерение | Результат | Покрытие |
|---|---:|---|
| Посекундная точность | **93,51%** | Восемь сценариев SUMO; 20 582/22 010 светофоро-секунд |
| Полнота зелёного / красного | **99,37% / 94,66%** | Те же контролируемые сценарии |
| Полнота жёлтого / красно-жёлтого | **22,64% / 56,51%** | Короткие цвета остаются слабым местом |
| Известное реальное окно видимого N | **148/153 = 96,73%** | Только зелёный/жёлтый, условная привязка часов |

Суммарный ложный зелёный сократился с 920 до 666 светофоро-секунд, но один
сценарий смены периода и красно-жёлтый на Т-перекрёстке ухудшились. Строгий
критерий отсутствия ухудшений не пройден.
[Измерения, графики и покрытие](results/README.ru.md).

## Код

- `app/api/`: загрузка, сохранённые модели, онлайн-пакеты и общая панель.
- `app/core/`: траектории, офлайн-анализ, геометрия и сохранение данных.
- `app/timing/`: причинная оценка цвета/возраста фазы и адаптация длительности.
- `scripts/`: рабочий процесс анализа, конвертация, миграция, упаковка и проверки.
- `tests/`: тесты оставшейся функциональности приложения.
- `results/`: компактные измерения и графики; исходные данные и прогоны остаются локально.

```sh
python -m pip install -r requirements-dev.txt
python -m pytest -q
python -m ruff check app scripts tests --select F821,F822,F823
```

Приложение проверено для локального использования. Публичный многопользовательский
хостинг и авторизация не входят в проверенный вариант развёртывания.
