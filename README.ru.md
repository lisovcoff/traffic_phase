# Traffic Phase

[English](README.md) · **Русский**

Восстановление фаз светофора по траекториям автомобилей при отсутствии прямой
видимости. Приложение на Python/FastAPI анализирует JSON или ZIP одного
перекрёстка, определяет повторяющуюся структуру движения и показывает машины
и оценённые сигналы в общем офлайн/онлайн-плеере.

**Статус:** работающий исследовательский прототип. Автоматическая обработка
и причинный онлайн реализованы; универсальная точность физических сигналов
ещё не подтверждена. Видео и ручная разметка используются только для проверки.

## Возможности

- Одна панель: весь архив, сохранённая модель и онлайн-поток.
- Автоматические наблюдаемые подходы (3/4), число фаз K, группы движений
  и гипотезы секций без заданной пользователем схемы.
- Каталог режимов/длительностей и онлайн по секундным наблюдениям на изученной
  офлайн-структуре.
- Машины, воспроизведение, пауза, скорость, перемотка и выбор точного времени.
- Сохранение моделей, истории пакетов и восстановление онлайн после перезапуска.

Оборудование и цвета остаются оценками. Пустующий подъезд, поворот с уступанием
и перекрытый поток могут давать неоднозначность. Новые длительности и необычные
продления требуют дальнейшей приёмки; текущая рабочая версия — v7.

## Запуск

Проверенная версия — **Python 3.12**. На Windows в корне репозитория:

```bat
INSTALL.cmd
START_WEB.cmd
```

Откройте **http://127.0.0.1:8017/visualization**. Проверка импорта:
`START_WEB.cmd --check`. Перед запуском обновлённой версии остановите старый сервер.

Для других ОС:

```sh
python3.12 -m venv .venv
. .venv/bin/activate
python -m pip install -r requirements-tested-py312.txt
python -m uvicorn app.main:app --host 127.0.0.1 --port 8017
```

## Как пользоваться

1. Прикрепите исходный **JSON или ZIP одного перекрёстка**, нажмите
   «Анализировать». Поддерживаемые файлы и сеансы обрабатываются автоматически.
2. Выберите запись и просмотрите машины/оценённые сигналы в плеере.
3. Для онлайн откройте завершённую модель, перейдите в «Онлайн» и выберите
   **JSONL** либо отправляйте пакеты на показанный адрес API.

`feed_manifest.json` и отчёт анализа не являются траекториями. JSONL загружается
в управлении онлайн-потоком; конец файла завершает конечное воспроизведение.
Данные и плееры сохраняются в `logs/intersection_projects/`.
Сохраните эту папку: скачанный JSON модели не содержит весь комплект для плеера.
[Контракт входов/API](docs/API.md); интерактивная документация доступна в `/docs`.

## Проверка точности

Обработаны шесть архивов и три отдельных JSON — всего 219 источников.
На 24 отложенных синтетических офлайн-примерах K совпал в 24/24 случаях;
это проверка симуляцией, а не видеоэталон оборудования. На 12 синтетических
потоках рабочая онлайн-версия дала 86,50% цветов. В узком известном окне
GREEN/YELLOW одной N получено 96,08%; после продления зелёного в копии входа
точность упала до 89,09%.

**95% на шести реальных архивах не доказаны.** Покрытие видео, ограничения часов,
отклонённые кандидаты и знаменатели опубликованы в [результатах](results/README.md).
[Почему нельзя назначить теоретический максимум](results/accuracy_limits.ru.md).

## Разработка и структура

```sh
python -m compileall -q app scripts tests
python -m pytest -q
python -m scripts.e2e_smoke
```

Для крупного регрессионного примера нужен Git LFS: `git lfs pull`.
Проверки сохранённых частных прогонов пропускаются в чистом клоне;
модульные тесты и API от локальных отчётов не зависят.
В чистом экспорте: **1 485 тестов прошли, 34 проверки локальных прогонов
пропущены**; отдельно все 34 прошли на сохранённых данных.
[Протокол проверки](results/repository_verification.json).

| Папка | Назначение |
|---|---|
| `app/` | Python: алгоритм, API, формирование интерфейса |
| `scripts/` | CLI, генераторы и средства воспроизводимой проверки |
| `tests/`, `.github/` | Тесты и CI |
| `config/` | Ресурсы отдельных прежних диагностических API |
| `docs/` | Архитектура, контракт входов и текущий статус |
| `results/` | Компактные результаты и ограничения точности |

Исходные данные, готовые HTML-плееры/отчёты, кадры и исследовательские выгрузки
исключены из Git и остаются на компьютере. `config` сохранён по проверенным
зависимостям; автоматический рабочий путь не требует именного профиля.
[Архитектура](docs/ARCHITECTURE.md) · [Статус готовности](docs/PROJECT_STATUS.md).
