# Traffic Phase

[English](README.md) · **Русский**

Восстановление фаз светофора по траекториям автомобилей, когда светофор напрямую
не виден. Загрузите JSON/ZIP одного перекрёстка и просмотрите машины и оценённые
сигналы в интерактивном плеере. Видео и ручная разметка используются только для
проверки; рабочий алгоритм их не получает.

Офлайн-анализ всего архива и причинный онлайн на сохранённой структуре реализованы.
Полная приёмка точности ещё не завершена: оборудование, цвета и смены режимов
остаются оценками, а по одним траекториям иногда неоднозначны.

## Запуск

Проверенная версия — **Python 3.12**. В корне репозитория на Windows:

```bat
INSTALL.cmd
START_WEB.cmd
```

Откройте **http://127.0.0.1:8017/visualization**. После обновления остановите старый
сервер через `Ctrl+C` и запустите снова. `START_WEB.cmd --check` проверяет импорты
без запуска сервера. В существующей локальной папке запускатель передаёт управление
репозиторию в `audit_checkout/`; у нового клона обычный корень проекта.

На других ОС создайте Python 3.12 venv, установите зависимости из
`requirements-tested-py312.txt` и выполните:

```sh
python -m uvicorn app.main:app --host 127.0.0.1 --port 8017
```

## Офлайн

1. Выберите JSON или ZIP с траекториями **одного перекрёстка**.
2. Нажмите **«Анализировать»**. Допустимые JSON и сеансы обрабатываются
   автоматически; ошибки отдельных файлов явно видны в неполном результате.
3. Выберите запись. Доступны пуск/пауза, скорость, перемотка и точные дата/время
   по Екатеринбургу (UTC+05:00). Задавать число фаз или готовую схему не нужно.

Модель хранит наблюдаемые подходы, гипотезы голов, число рабочих состояний K,
группы конфигураций, статистику длительностей, возраст старта машин внутри фазы
и происхождение данных. Есть условные схемы с 3 и 4 подходами. Разные записи
сохраняют отдельные часы и track ID; разрывы не сшиваются в выдуманную историю.

Результаты находятся в `logs/intersection_projects/<model_id>/`. Повторное
открытие не запускает подбор. Скачанная модель описывает структуру; это пока не
переносимый комплект исходного архива и всех плееров. Для просмотра сохраняйте
локальную папку проекта. Прерванный незаконченный офлайн-анализ пока автоматически
не возобновляется.

## Онлайн

Нажмите **«Онлайн»** в той же панели. Приложение создаёт подключение и показывает
адрес приёма пакетов. Структура, K и гипотезы оборудования берутся только из
офлайн-модели. Для демонстрации выберите JSONL: одна строка — один секундный пакет.
Доступны скорость повтора, просмотр исходной истории по времени и возврат в эфир.

Пакет содержит `sequence`, `timestamp_ms` и `vehicles`. У машины — постоянный
`id`, `zone_in` и уже доступные `detections`. У детекции — `millis`,
`centroid_x`, `centroid_y`, `zone` и при наличии `speed`, `lat`, `lng`.
Время детекций не должно превышать время пакета. Будущий `zone_out` запрещён.
Географические координаты помогают, если поле скорости поставщика ненадёжно.
Без машин отправляйте пустой массив: отсутствие потока само по себе не означает красный.

Пакеты и исходные ответы сохраняются транзакционно в SQLite. Повторы идемпотентны,
противоречивые повторы и будущие детекции отклоняются. После перезапуска состояние
восстанавливается из журнала. История показывает ответ, действительно выданный
тогда, а не позднее исправление. Подробный контракт: [онлайн](docs/INTERSECTION_ONLINE_RESULTS_20261019.md).
Документация HTTP API доступна по адресу `/docs`.

## Проверки и ограничения

Численное офлайн-восстановление ранее дало 68/72 и 24/24 совпадений **латентного K**.
Рабочие конфигурации светофоров — отдельная величина: текущая проекция дала
54/72 и 18/24 на уже раскрытых регрессионных сценариях. Эти показатели нельзя смешивать.
Исправление проекции снизило ошибку основных цветов с 6,79% до 5,99% и с 9,18% до
7,47%; ухудшений в этих 96 сохранённых случаях не найдено. Это не новая независимая проверка.

На двух разработочных онлайн-потоках со сменой длительностей точность основных
цветов около 89% и 88% с учётом UNKNOWN, после 180 секунд начальной синхронизации.
На уже размеченном реальном фрагменте все 3 включения зелёного попали в ±2 секунды,
но есть лишние включения, а жёлтый и красный менее точны. Офлайн-модель включает
ту же запись, связь часов условная; универсальная точность этим не доказана.

Переменные режимы, редкий поток, скрытые секции и неизвестные схемы ещё требуют
дальнейшей проверки. Пустой подход может остаться невидимым; поворот не доказывает
стрелку. Без различающих наблюдений нельзя назвать причиной продления пожарную
машину или кортеж. Процент уверенности модели не является калиброванной вероятностью лампы.
