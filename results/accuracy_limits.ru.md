# Какая максимальная точность возможна

[English and measurements](README.md) · **Русский**

Численный теоретический максимум на шести архивах **не установлен**. Полной
независимой истории всех ламп нет ни для одного архива. Даже полная разметка
позволила бы измерить ошибку, но сама по себе не доказала бы оптимальность
алгоритма среди всех возможных алгоритмов.

По одним машинам цвет иногда неоднозначен: поток может стоять на красном или
на зелёном за препятствием; без машин сигнал вообще не проявляется. Поворот
не доказывает наличие стрелки, а пустующий подъезд может скрывать отдельную фазу.
В тестах уже есть проверяемый пример одного входа с двумя допустимыми планами
K=3 и K=4. Это доказывает неоднозначность задачи в общем случае, но не задаёт
численный потолок именно наших реальных архивов.

Из доступного видео Свердловского проверялась основная N в двух известных
окнах с условной привязкой часов: 18/18 переключений в пределах 5с, 11/18 в
пределах 2с, одно лишнее появление красного. На коротком окне GREEN/YELLOW
получено 147/153=96,08%, однако остальные цвета и головы этим не проверены.
После искусственного продления зелёного на 12с результат 147/165=89,09%.

На 12 синтетических потоках общий результат рабочей версии — 86,50%, но
распознавание жёлтых секунд — 13,22%, красно-жёлтых — 4,65%. Красный занимает
большую часть времени; средняя полнота по четырём цветам — 49,33%. Поэтому
улучшать нужно сами переходы и ошибки ложного зелёного, а не только общий
процент. Подробные числители и знаменатели приведены в общем отчёте.

На Энтузиастов видимая E размечена, но привязка JSON к видео ещё не принята.
Невидимую N при ДТП нельзя считать размеченной по состоянию E. Для остальных
четырёх архивов нет принятого независимого эталона ламп; результаты по движениям
не заменяют точность цветов. Таблица покрытия и происхождение чисел находятся
в [общем отчёте](README.md) и [summary.json](summary.json).

95% и выше на отдельных хорошо наблюдаемых интервалах возможны; 95% на всех
шести архивах сейчас не подтверждены. Ни недостижимость такого результата на
этих данных, ни конкретный максимальный процент не доказаны.

Поэтому честный критерий следующего этапа — улучшение на заранее отделённых
контролях без ухудшения обычных сигналов, жёлтого, K2/K3 и продлений. Отдельно
измеряются мгновенный ответ, история с задержкой, UNKNOWN и ложный зелёный.
Видео используется только для проверки, а не как вход модели. Текущие
экспериментальные улучшения этот критерий не прошли; рабочая версия остаётся v7.
