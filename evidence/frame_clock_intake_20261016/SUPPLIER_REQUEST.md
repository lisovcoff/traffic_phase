# Запрос по времени исходной выгрузки

Для записи Ленина—Свердловский 27.02.2025 требуется небольшой исходный фрагмент
лога/экспорта с несколькими соответствиями **одного и того же exposure**:

1. camera/frame ID;
2. PTS кадра экспортированного MP4 и его time_base;
3. `detections[].millis` этого exposure;
4. версия/название экспортера и источник соответствия;
5. определение millis: время exposure/детекции/получения/обработки и возможная
   задержка/погрешность относительно exposure;
6. формирование надписи времени камеры: округление/усечение, частота обновления,
   связь с exposure, часовой пояс; что происходит при offline processing.

Желательны несколько пар из разнесённых частей записи, не только один кадр.
Если кадры MP4 были переупакованы/обрезаны/перекодированы, нужна связь их PTS с
original camera frame IDs. Не нужно подбирать offset по движению автомобилей
или сигналам и не нужны все архивы. Известно со слов пользователя, что часы —
камеры; требуется не повторное подтверждение этого, а механизм frame timestamp.

Машиночитаемый шаблон: `config/frame_clock_links_template.json`.
Если нужный лог недоступен, достаточно явно указать неизвестные пункты;
числа погрешности и PTS по среднему FPS выдумывать не следует.
