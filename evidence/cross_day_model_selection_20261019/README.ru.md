# Междневной перенос: v4 → v7

Итог: [подробный отчёт](../../docs/CROSS_DAY_RECOVERY_RESULTS_20261020.md),
`summary.json`, `release_v7/`, `archives_v7_complete.json`,
`projection_v3_regression.json`, `final_control_protocol.json`, `final_control/`.

Проверка приложения: `browser_v7_verified/` — цвета из журнала и плеер,
`browser_live_v7/` — реальные JSONL через обычный HTTP, `verification_complete.json`.
`release_manifest_v2.json` хранит SHA Git-объектов, рабочих исходников и компактных
свидетельств. Первый манифест также сохранён; повторный учитывает нормировку
окончаний строк `.gitattributes` при записи в Git.

18/18 ±5с относится только к двум уже известным окнам видимой N при условной
связи часов. Остальные четыре архива: улучшился прогноз движений, независимой
точности ламп нет. Новый восьмисценарный контроль цветов:86,44% против86,57%,
прирост не получен. Рабочий K на старом материале:70/72 и24/24.

V6 с дообучением длительностей отвергнут: улучшение синтетики не перенеслось на
жёлтый реального видео. Его артефакты и ранние неудачные проверки сохранены.
Это не рабочий режим. Старый эксперимент2D.1 не использовался.

Большие причинные пакеты, baseline v4 и кэши находятся локально в
`.web_runtime/cross_day_model_selection_20261019/` и прежних каталогах кэшей.
Результаты численного офлайн-решателя повторно использованы только под
проверенными SHA/предыдущей производственной проверкой; свежие сырые потоки
исключённых JSON проверены отдельно. Полный холодный пересчёт всех125 источников
этим повтором не объявляется. Исходные пользовательские архивы в Git не включены.
