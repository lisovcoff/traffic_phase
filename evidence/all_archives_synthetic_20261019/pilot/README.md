# Preliminary pilot, retained without replacement

These two receipts precede the frozen main simulation environment and final
scorer. They are not members of the final benchmark denominator. The pilot
revealed excessive field-of-view duration relative to source track samples;
the final generator samples a shorter view. The solver was not tuned or changed.

The original pilot movement-composition score incorrectly compared `E->_W` with
the production canonical stream `E->W`. Final evaluation normalizes both names.
The pilot also scored only overlapping history; final evaluation_v2 counts the
whole requested recording, UNKNOWN included, and uses the shared production
color-transition function. Original receipts remain unchanged for audit.
